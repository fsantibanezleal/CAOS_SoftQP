# C13: Published building-energy model

Category: energy. Source: OSQPSlack MIT synthetic building model.

## Why this case exists

The source-faithful published model couples two thermal zones, a battery and grid supply over one day. It preserves mixed penalty families.

## Formalization

96 intervals of 0.25 h; 20 kWh battery; quadratic comfort, grouped peak grid cost, elastic battery-health band and Huber HVAC ramp cost.

Original rows: 1255; hard rows: 773; physical units: kW, kW/h, kWh, °C. Row labels and hard/soft policy come from `data-pipeline/pipeline/softqp_rows.py`.

## Expected results

The published native penalty path and exact reference lift run the same mixed objective. A separable adapter is incompatible; it must not quietly replace group or Huber terms.

## Executed compatibility

| Method | State | Reason |

| generalized | available | Original-space metrics exported. |

| daqp | incompatible | The DAQP reference adapter supports separable elastic side costs, not grouped or Huber penalties. |

## Validation anchor

The independent lifted formulation evaluates the same original objective. Available catalog cells must satisfy normalized objective discrepancy at most 1e-6 and raw hard-row error at most 1e-6. Scalar cases additionally have closed-form checks. Native status, recovered x/y, cost components and lower/upper physical violations remain in the [scientific record](../../../data/derived/softqp/C13.json).
