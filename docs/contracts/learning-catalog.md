## Shared admission and safe substitution

The reader scale follow-up keeps these eleven boundaries and all field spellings. Its internal Python ReadRequest/read_artifacts API admits at most256explicit requests in order, preserving duplicates or refusing the call. Fresh public calls reopen all reachable JSON/numeric/relevant-schema bytes; unrelated catalog payloads are not population-validated by a single-root read. Bounded shared snapshots are local to one explicit batch, with exact typed reference/hash checks, usage-specific semantics and cached-ancestor cycle refusal. An immutable lexical alias index avoids per-write catalog filesystem walks; current path/junction/checkout and atomic publication checks remain. Exact snapshot/eviction/concurrent-writer limits are in docs/design/features/method-extension/reader-admission.md. The new unit remains unadmitted until regression/full-count fixture evidence and independent review.

Historical committed provider examples retain their acceptedcb20producer hash and exact source bytes in the never-executed tests/fixtures/learned-contracts/provider-source.py.fixture. They are read by the current consumer as historical producer artifacts, never regenerated or relabeled. The fixture loader accepts only that independently pinned snapshot or actual current producer bytes with a matching expected hash; unknown source identities refuse. Existing JSON/numeric examples and original195test definitions are unchanged.

Scientific `number` fields across all eleven schemas declare `format: lossless-float64`, enforced by the strict reader. Integers must convert to finite binary64 without losing their exact submitted value; overflow and rounding refuse normally before source or proof admission. Exactly representable large integers and binary64 dyadics remain valid within existing field limits. Integer metadata remains exact JSON integer. Exact rational proof preserves admitted integers directly and interprets admitted floats as their exact binary64 dyadics. Canonical byte checks prevent rounded decimal-token substitutions. See LC-014 and the U1-01 bounded integer witness regression; no R4 population or keyset changes.

AdmissionContext is independently supplied trust, not parsed from a submitted scientific document. It binds actual source/lock byte hashes, protocol payload and registration identity, sealed original/source records, exact parent raw-byte catalog, fit-source IDs and expected primary/control/diagnostic keysets. Every non-missing non-protocol artifact has a checked protocol_ref. Scientific production requires a registered protocol. A recomputed outer hash cannot authorize changed coefficients, ancestry, split, checkpoint, normalizer, calibration or registration.

Boundary Artifact is frozen and returns detached views; typed payload dictionaries name each of eleven boundaries. Draft2020-12 schemas enforce exact IDs/types/keys, while semantic readers enforce cross-boundary math/provenance. References bind actual read_bytes. Writers emit sorted UTF8/LF finite JSON and publish new external files atomically without overwriting inputs. Unknown types, bool-as-number, duplicate keys, NaN/Infinity, executable numeric formats, traversal, symlink/junction escapes and checkout outputs refuse before a partial artifact survives.

Missing records can be serialized/displayed without inventing payload. Required dependency admission refuses missing records. Available scientific artifacts and fixture providers are distinct. Runtime/model/weights absence is a missing/failure state on a compatible key, never mathematical incompatibility. Every declared state is exercised in test_missing_and_fixture_lanes. Real missing runtime/oracle paths are exercised by test_oracle_and_runtime_missing_records_preserve_denominators. Fixture replacement is explicit; the production lane refuses it even after changing the local purpose/state and outer hash.
