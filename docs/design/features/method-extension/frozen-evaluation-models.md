# Frozen model inputs for held-out evaluation

Status: proposed pre-data interface. Preserve existing frozen-inference/calibration v1 bytes and readers. This extension supplies immutable train-only preprocessing and final calibration disposition without mounting fitting or calibration payloads in held-out inference.

## Preprocessing freeze

A new typed inference-preprocessing/1 receipt binds independently verified actual TrainingRun, FrozenInference, selected checkpoint, method/seed, protocol/population/P1 and train/validation phase digests. Its writer runs at fitting completion under the admitted training plan. For learned OSQP, copy the already sealed train-only normalizer rows for every required head: canonical row digests, exact head domain and phase identities must match the selected checkpoint. Do not recompute from another role. For graph inference retain exact checkpoint class statistics/prior and no MLP normalizer. Reuse existing frozen numeric weights without another large copy. Both writer/reader verify shapes, finite values, unique sorted identities, digests and selection ancestry. Produce this receipt before fitting roots become unavailable. Missing preprocessing is explicit unavailable model state, never a fitted default. Existing v1 artifacts remain readable without claiming this additional boundary.

## Final calibrated bundle

A new evaluation-model-bundle/1 is published after actual read_calibration verifies its observed receipt while legitimate calibration-role inputs are still available. The publisher consumes verified frozen weights/checkpoint, independently pinned preprocessing and actual calibration admission. Bind method/seed/source/protocol/population/P1, all run/checkpoint/frozen/preprocessing/calibration identities and selected numerical weights. Graph threshold is exactly the registered grid maximizer with larger-threshold tie rule; L2WS is explicitly not-applicable with no invented classifier values. Independently expected digests come from controlled stage supervision and frozen evaluation policy, never the attempted bundle itself. Reject arbitrary caller calibration mappings which have not traversed that genuine reader.

Reference existing weight files through logical root aliases resolved by independently pinned runtime policy. Serialize no machine path and create no writable hardlink alias or additional complete weight copy. Retain an immutable small calibration receipt as provenance; do not import its probability files or original role payloads into evaluation. The held-out consumer opens only final bundle, preprocessing, existing frozen numerical artifacts and that immutable receipt. It verifies every independently expected digest, tensor shape/finite values, selection/provenance/fixture lane, normalizer layout/digests, graph prior, and threshold/tie rule. It never invokes read_calibration, fitting/calibration phase readers or global descriptors. The previously independently verified calibration receipt establishes past observed computation; the new reader does not claim a replay of its unavailable original data.

## Fixed complete roster

Freeze six ordered dispositions, two learned methods crossed with seeds41001/41002/41003. Available entries require complete heads and all receipts. Missing/failed entries retain exact independently sealed job failure/absence evidence; initialized or partial models remain unqualified. No alternative seed/head subset/retry/threshold is selected from held-out data. Future held-out authority independently pins the complete final roster, including failures, before opening test inputs or generating native test proof. Failed learned models produce eligible failed statuses rather than incompatible cells or missing denominators; the deterministic matrix remains intact. This module and caller-created rosters grant no test access.

## Excluded controls

Physically remove global, fitting, calibration and original training-result roots, then verify final consumer only opens declared artifacts. Compare actual model/normalizer/weight/prior/threshold bytes. Refuse altered mean/scale/prior/threshold, checkpoint/seed/role relabel, fixture promotion, incomplete head/roster, ignored expected hashes, fake calibration mapping, changed numeric file, unsafe aliases and duplicated dispositions. No scientific training or held-out execution is authorized by these controls.

## Product hooks

Call `publish_preprocessing` with the verified training plan and independently observed run, frozen receipt and selected checkpoint digests. It rereads the actual training run before writing `preprocessing.json`. Call `publish_bundle` under the admitted calibration plan with the exact preprocessing and calibration digests. It invokes the existing calibration verifier while its role is available and stores only the canonical receipt and a small `bundle.json`. Supervision supplies the expected digests and three distinct artifact-root aliases in `ModelTrust`. The held-out path uses `read_bundle` and reads one selected head at a time from existing frozen numeric bytes. Use `publish_roster` and `read_roster` with six independent model or failed-model trust records. The missing or failed record refers to a separately pinned canonical job evidence document. The production dispatcher hooks and independent test unlock authority remain separate integration work.
