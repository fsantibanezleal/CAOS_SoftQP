# Isolated phase input admission

The trusted preflight caller supplies its externally configured AdmissionContext, the nominated dataset and split IDs, and a semantic-key-to-catalog-ID nomination for every required feature and label. Preflight automatically includes every dataset problem. The accepted semantic matrix defines MLP applicability and exact positive-definite graph applicability. The label-status keyset independently fixes the graph and label slots, including every trajectory frame. The lifted-method projection of source-status fixes held-out source slots. The strict dataset supplies the complete problem population and verifies source assignments, parent and content exclusions and train-only fit membership. Diagnostic fixture controls follow their exact admitted lift curvature. They are confined to the fixture lane.

A nomination of an unavailable feature or label still needs its original strict missing envelope, with a null payload and its exact reason. Its semantic address comes from trusted external nomination because the existing missing envelope has no typed parents. An available feature or label must name the precise nominated problem, split and protocol under the existing numerical and normalization rules. Distinct artifact IDs cannot substitute for a duplicate key. The complete receipt binds the graph, catalog IDs/paths/raw hashes, source and problem identities, fit set, producer, generator, dependency lock, settings, registration, source root and protected output roots. It accounts for the input population independently of the downstream 42,816 method/control outputs.

The preflight review supplies its digest independently. Materialization takes that digest, creates an absent external role directory using exclusive mkdir and copies only that role's rehashed problem, feature and label bytes. The final manifest is published atomically under its final name after all byte copies are complete. A concurrent caller cannot take over a reserved destination. An owned unpublished failure removes its own writes. While unlinking the temporary name, the reader accepts it only as a hard link to the same verified final manifest. The manifest binds the role, preflight digest and local names/raw hashes. The caller independently obtains that manifest digest, role and fixture policy and supplies all of them to PhaseInputReader. A digest calculated from submitted content at the consumption site does not establish authority. Input roots and publication parents require controlled ownership and immutability while validating paths and copying. This is an application-level publication boundary across ordinary concurrent callers, not protection against a writer with permission to swap directory entries between stat and open.

A reader verifies the manifest once and reopens only the requested local payload on each read, checking its exact bytes, current path and sealed identity. It uses preflight semantic admission and does not traverse original typed ancestry. Fixture admission requires separate explicit permission. The initial surface supports train, validation and calibration. Test export and test-role open are refused before I/O. The general production fit/calibration entry points retain LC-019. Checkpoint, resume, test inference, freeze and evaluation need independently reviewed contracts.

The four-problem provider lane verifies source mechanics and reports software fixture states. Registration, large population throughput (600 seconds, 8 GiB, one worker), and actual production entry point training, calibration and held-out evaluation remain separate gates.
