# Sealed source/frame projection for measured evaluation

Status: proposed pre-data interface. This in-process API preserves the v2 artifact, preflight and role-manifest formats. It grants no test admission and produces no scientific execution authority.

`StreamingPhaseReader.read_sealed_frame_pair(frame_id)` returns four detached values: `source_raw` and `frame_raw` immutable canonical bytes, and exact detached `source_ref` and `frame_ref` mappings from the already sealed local-role manifest. It opens each local file afresh, requires its single-link exact path, expected stored SHA and exact artifact kind/ID, checks the referenced source is exactly the nominated local source, and checks both source and frame roles equal the reader role. It never returns a reconstructed original problem, canonical lift, numerical feature, label, normalizer, oracle or model.

The current `_stored` implementation will share a private checked `(raw,document)` helper with this accessor, preserving existing reader behavior and file-open counts. Decoding the small frame header to select its source is broker work; the broker discards parsed numerical payloads. No global, fitting or another role root is mounted. Existing `StreamingPhaseReader` test-role refusal remains in place. A distinct independently approved frozen-checkpoint/calibration/native-test authority will be required to admit a future test reader; this accessor cannot create one.

The fixed scientific evaluator must start its supervisor `perf_counter_ns` observation and whole-trial 10-second deadline before calling the accessor and delivering its bytes. The recorded full cost ends only after the child has decoded and independently validated both original raw artifacts, reconstructed the physical and canonical problem, computed any features and inference, set up and solved every attempt, recovered the result and checked original-space acceptance. Thus broker file opening, route-header parsing and IPC are counted, rather than hidden preprocessing outside the measured segment. Separately retain the child's numerical timing as secondary telemetry. Model import/loading remains independently observed startup per R4; no earlier source/frame numerical conversion or graph may be reused in the trial. Fresh calls on every warmup and measured repetition preserve byte freshness. A broker timing without the actual guardian/nonce/job/source-bound release and result observations is not an accepted scientific timing.

The evaluator's independent consumer must verify raw bytes against these exact references and source linkage before recomputing the canonical candidate checks. A same-size mutation, alternate source, role relabel, fixture substitution, absent frame, malformed manifest or reparse/hardlink escape refuses before solver dispatch. Tiny software tests must show exactly the two local files are opened, detached return mappings cannot mutate the reader, repeated calls observe mutation, and the returned bytes reconstruct identically to the ordinary `read_problem` path. The existing non-test fixture lane suffices for this interface test and does not unlock held-out data.
