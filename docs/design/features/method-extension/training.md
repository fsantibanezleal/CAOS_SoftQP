# Phase-isolated training, numeric checkpoints and calibration

This is a prospective source design for R4. Scientific execution requires genuine I1, the separately admitted full product CPU profile and the later source-specific gates. The legacy v1 contracts and current v2 stream/checkpoint bytes remain supported. No model training or calibration is part of this design handoff.
