# Linked original-row inspection

Contract frozen before implementation, 2026-11-05. This unit answers: which original constraint row is selected, what coefficients and hard/soft interval define it, and where does the verified returned original-space Ax lie?

The URL case/method/row/native selection remains authoritative. The shared shell's installed 0.20.0 LinkedViewProvider, useLinkedItem and useLinkedCursor project that selection into presentation state; no second domain store is introduced. Entity identity is `case_id:row.id`. Direct scene/panel actions retain their origin; loading, external URLs, back/forward and changed source identities reconcile to the actual loaded row. Loading or expired native input clears selection/cursor. A different case never temporarily borrows the old case's coefficients.

The structural cursor is **constraint row ordinal [1]**, from 1 through the actual row count, integral, mapping to URL `row = ordinal - 1`. It is neither time nor an iteration. Moving it selects the corresponding original matrix row and redraws its real interval/Ax companion. The matrix selection and interval plot carry visible markers bound to that same ordinal. The plot's horizontal axis is original row value in that row's unit; the ordinal selects which plot is inspected, not its physical x coordinate. Mixed-unit rows are never combined on a numerical axis. Only the system view exposes this cursor; dynamics retains its existing recorded frame/time semantics.

The panel renders a bounded three-row neighborhood, each with actual lower/upper limits, mask and full Ax or explicit unavailable state. Selecting a neighbor re-centers the window, so every row remains reachable with the existing native row selector or ordinal range. The selected detail uses sparseProblemView/selectedInterval without changing their math: full CSC Ax, at most four coefficient terms with explicit omission count, bounds including absent infinite ends, unit and replay/native provenance. The companion interval plot uses finite bound/Ax endpoints with finite padding; no Ax marker is drawn without a compatible verified returned vector. The numerical source is the current supplied artifact, never a hand-entered result.

Grouped/no-coefficient records show an explicit unsupported inspection reason. Incompatible/unknown methods may still inspect exported coefficients and policy but cannot gain a candidate marker or Ax. Expired native inputs show no previous replay/native content. The browser performs no optimization, interpolation of iterates, or scientific acceptance. Existing V5 formulas, one-column coefficient layout, normal cones, hard-indicator policy and full-Ax helpers remain unchanged.

Shell layout, stage floors, navigation and generic state APIs remain shell-owned. This unit adds no shell CSS override. Installed 0.21 adoption, sectioned story panels, focused browser/source comparisons and independent review are prerequisites for final composition qualification.
