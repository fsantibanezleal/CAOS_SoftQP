# Shared scientific reader shell

## What and why

The shell supplies consistent bilingual pages, Focus workbench, accessible controls, plot stages and interactive chart behavior. Product methods remain outside the shell.

## Install: exact declared version

`@fasl-work/caos-app-shell@0.19.1`. Numerical source validation uses Python 3.12. See the repository requirements rather than substituting an ambient version. Native source installation additionally requires a C/C++ compiler and CMake; clean published-wheel installation has its own release check.

## Usage

Use CaseWorkbench for one selected case and DocPage/DocSection for cross-case material. BarChart and UPlotChart retain accessible data tables, units and keyboard interactions.

## Applying it here

The product uses six materialized routes, physical-unit filters and verified experimental/case readers. Theme and language checks are part of the full browser matrix.
