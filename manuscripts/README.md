# Scientific manuscript sources

The [soft-constraint study](soft-constraint-study/main.tex) contains the numerical formulation, source comparison, prospective protocol and negative timing result. Build figures with `python manuscripts/soft-constraint-study/figures.py` and the PDF with `python manuscripts/soft-constraint-study/build.py`. The prepared PDF is written to `output/pdf/softqp-technical-report.pdf`.

The technical report is published under CC BY 4.0: [concept DOI](https://doi.org/10.5281/zenodo.23851659), [version 0.01.000](https://doi.org/10.5281/zenodo.23851660). The public record and a fresh unauthenticated download were verified against the frozen 393669-byte PDF (SHA-256 `83b94c7582def9d62753147a4766a9e3c2ee62728aad15ed4d3fd50ed4584f26`). Code/evidence remains in the product and engine repositories; the manuscript publication contains one PDF only.

The separate [directional coupled peak study](coupled-peak-study/README.md)
contains the prospective 210-instance revision, complete negative heldout result,
independent evidence/figure/archive acceptance and guarded report-generation source.
It is a standalone computational-study report. The existing app report, product
version, historical notebooks and qualified-release gate remain distinct.
